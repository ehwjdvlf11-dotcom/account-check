User Guide & Compliance

안전한 계정 사용 가이드

안정적인 유지를 위해 열람 전 반드시 숙지해 주세요.

01. 로그인 및 초기 확인
  • 전달받은 정보로 로그인 후 OTP(2단계 인증)를 진행해 주세요.
  • 품질이 좋지 않은 IP(무료 VPN 등) 환경에서의 로그인은 자제해 주세요.
  • 로그인 즉시 서치밴(Search Ban) 여부를 테스트하고 문제 시 즉시 문의 바랍니다. (※ 정상 노출 확인 이후 발생한 서치밴은 사용자 책임입니다.)
02. 12시간 교환 규정
  • 본 거래는 정상 노출 상태의 X 계정 양도입니다.
  • 발급 수령 시점부터 12시간 이내 계정 자체의 중대한 문제 확인 시 1회 교환됩니다.
  • 단, 구매자 과실이나 X 시스템/운영정책 위반으로 발생한 제한은 제외됩니다.
03. 정보 변경 및 보안 주의
  • 생년월일 정보는 절대 변경하지 마세요. (계정 잠금 유발)
  • 아이디·닉네임·프로필 사진 변경은 구매자의 재량이나, 계정 정보(ID/PW/OTP)는 타인과 공유하지 말고 안전하게 보관하세요.
04. 안정적인 계정 사용 (워밍업)
  • 초기에는 반복적인 게시글 도배를 피해 주세요.
  • 팔로우/팔로잉 추가, 리트윗, 좋아요 등 가벼운 기본 활동 위주로 계정을 적응시키는 것을 권장합니다.
